# GNOMES — Android prototype

Первый играбельный прототип idle/incremental-игры про гномов-шахтёров.

## Что уже работает

- Шахта живёт в реальном времени: гномы сами выбирают породу, бегут к ней и добывают ресурс.
- Удержание большой кнопки внизу ускоряет симуляцию ×4.
- 6 ступеней гномов:
  1. обычный гном;
  2. продвинутый гном;
  3. гном с двумя кирками;
  4. гном на буровой;
  5. гном на экскаваторе;
  6. железный гном-голем.
- 10 гномов текущей ступени объединяются в 1 гнома следующей ступени.
- Каждый тип имеет собственные добычу, скорость, боевой урон и грузоподъёмность.
- Породы: камень, серебро, золото, алмаз, обсидиан, древний кристалл.
- Обсидиан и древние кристаллы регенерируют. Если DPS ниже регенерации, жилу практически невозможно добить.
- Добыча не попадает игроку мгновенно: гном несёт её в сундук. На экране видно груз и заполнение мешка.
- Сундук есть всегда, уничтожить его нельзя.
- Только бесы и Король бесов пытаются добраться до сундука и крадут уже накопленные ресурсы прямо из баланса игрока.
- У сундука можно нанять и улучшать гнома-стража. Он автоматически атакует врагов рядом с сундуком, в первую очередь воров.
- Враги: бес, демон, каменный голем, водный голем, огненный голем, Король бесов, Король демонов, Король элементалей.
- При появлении врага шахтёры бросают добычу и бегут в бой, после чего возвращаются к работе.
- Опасности: обвал, яма, лава, поток воды. Гномы могут оглушаться, смываться или погибать.
- Артефакты дают постоянные бонусы: защита, урон по врагам, подавление регенерации, скорость.
- Система рун. Руну можно нанести на:
  - любой класс гномов;
  - глобальные улучшения;
  - артефакты;
  - сундук;
  - стража сундука.
- Руны влияют на добычу, доход, боевой DPS, скорость, выживаемость и борьбу с регенерацией.
- Прогресс автоматически сохраняется в SharedPreferences.

## Технологии

- Java 17 (исходники)
- libGDX 1.14.2, модули `core` + `lwjgl3` + `android` — как у DOT
- Gradle 9.5.0 + Android Gradle Plugin 9.3.1
- Daemon JVM 25 через `gradle/gradle-daemon-jvm.properties`
- Android SDK 36

Персонажи, техника, враги, сундук, руны, камни и эффекты сейчас рисуются программно. Это позволяет быстро менять размеры, анимации и механику, не переделывая набор спрайтов на каждом раннем тесте.

## Запуск на Ubuntu (как DOT)

Десктоп без Android SDK:

```bash
./gradlew -PskipAndroid :lwjgl3:run
```

## Запуск на телефоне

```bash
./gradlew :android:assembleDebug
./gradlew :android:installDebug
```

APK:

```text
android/build/outputs/apk/debug/android-debug.apk
```

В Android Studio открыть папку `Gnomes`, дождаться Gradle Sync и выбрать конфигурацию `android` плюс подключённый телефон.

В проекте есть bootstrap-скрипт `gradlew`. При первом запуске он скачивает Gradle 9.5.0 в `~/.gradle/gnomes-bootstrap/9.5.0`. Нужны `curl` или `wget` и `unzip`. Daemon JVM 25 задаётся в `gradle/gradle-daemon-jvm.properties` — та же схема, что у DOT.

## Что логично делать следующим проходом

1. Отточить поведение гномов и маршруты к стенам/сундуку.
2. Сделать полноценную анимацию ходьбы, удара киркой, переноски мешка, буровой и экскаватора.
3. Добавить отдельные способности элементальных врагов, а не только различия в характеристиках и внешности.
4. Сделать генерацию уровня именно как систему стен/туннелей, чтобы неправильное разрушение стены могло физически запускать обвал.
5. Настроить экономику и темп эволюции 10 → 1.
6. Добавить звук, вибрацию, меню, паузу, настройки и нормальный экран начала игры.
7. После стабилизации механики заменить/доработать процедурный арт финальными спрайтами и анимациями.
